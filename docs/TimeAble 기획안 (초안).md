# TimeAble 기획안 (초안)

Nov 9, 2026 · @박상훈

TimeAble(타임에이블)은 등록한 학생 전원의 시간표를 하나의 복셀 지형도로 바꿔, 공통 빈 시간을 호수와 마을로 보여주는 웹 서비스다. 과제 결과물이자 캠퍼스 바이럴을 노린다.

## 개요

등록한 학생 전원의 시간표를 합쳐, 공통 빈 시간을 복셀 지형도 한 장으로 보여주는 웹 프로그램이다. 과제 결과물이면서 공유로 퍼지는 것까지 목표로 한다.

핵심 원칙은 두 가지다.

- **빈 시간이 주인공**: 그룹마다 고유한 "빈 공간의 모양"이 공유 동기를 만든다.
- **기본 화면은 덜 보여주고, 다가갈 때 깊어진다**: 첫인상은 깔끔한 디오라마, 세부 정보는 줌·클릭 시에만 드러난다.

그룹을 매번 골라 만드는 방식이 아니라, 추가한 모든 학생을 한 지도에 일반화해서 보여준다. 사람이 늘수록 지도가 커지는 게 아니라 지형이 정교해진다.

## 서비스명과 브랜딩

서비스명은 **TimeAble**(타임에이블)이다. 시간(time)과 가능한(able)을 합친 이름이자, timetable과 겹치는 말장난이다.

- **표기**: 소문자 timeable은 "티미어블"로 읽히고 timetable 오타로 보이기 쉽다. 가운데 A를 대문자로 쓴 TimeAble을 기본으로, 한글 "타임에이블"을 병기한다.
- **로고 색 분리**: Time은 흙색, Able은 호수색으로 나눠 소문자로 써도 경계가 읽히게 한다.
- **로고 킥**: timetable에서 t 하나가 빠진 자리를 작은 호수 블록으로 채운다 (time▢able). "시간표의 빈 칸에서 만난다"는 콘셉트를 로고 하나에 담는다.

## 사용 흐름

사용자는 시간표를 넣고, 지도를 감상하고, 수위로 좁혀서, 투표로 확정한다.

1. **시간표 입력**: 포털 시간표 캡처 OCR 또는 붙여넣기. 알바·통학 등은 "애매"로 직접 덧칠한다.
2. **지도 감상**: 추가한 학생 전원이 한 장의 주간 대륙으로 합쳐진다. 기본 화면은 지형과 소품만 보인다.
3. **수위·필터 조절**: 최소 인원(수위), 모임 길이, 필수 인원으로 후보를 좁힌다.
4. **후보 확인**: 호수를 누르거나 추천 리스트에서 누가 오고 누가 빠지는지 본다.
5. **투표와 확정**: 링크 공유 → 호수에 깃발 → 확정 → .ics 내보내기.
6. **공유**: 지도를 포스터 이미지나 짧은 클립으로 저장해 SNS에 올린다.

## 주간 대륙 지형도

일주일 전체가 하나의 대륙이다. 가로는 요일, 세로는 시간, 높이는 그 시간에 수업이 있는 사람 수다.

- **산맥**: 대부분이 바쁜 시간. 전원이 바쁜 봉우리엔 눈이 덮인다.
- **분지·호수**: 많은 사람이 비는 시간.
- 학과·학년마다 특유의 지형이 생긴다 (예: 월\~수 오전 고원, 점심 계곡, 금요일 오후 평야).

### 수위 슬라이더

수위 = "최소 몇 명이 비어야 하는가". 그룹을 고르는 대신 물 높이만 조절한다.

- 수위를 낮추면 많은 인원이 겹치는 깊은 호수만 남는다.
- 수위를 높이면 소수만 모이는 작은 호수가 여기저기 생긴다.
- 숫자 필터를 풍경의 변화로 바꾸는 장치로, 아트워크와 기능이 하나가 되는 지점이다.

### 지명 자동 생성

호수와 산에 이름을 붙인다 ("목요일 오후의 큰 호수", "화요일 3교시 협곡"). "목요일 호수에서 보자" 같은 말이 친구들 사이에 퍼지는 것이 바이럴의 킥이다.

## 복셀 렌더링과 활동 매핑

렌더링은 복셀(블록) 스타일로 한다 (친구 아이디어). 시간표는 원래 30분 격자라서 격자가 그대로 블록이 되고, 데이터와 그림이 1:1로 맞는다. 보간으로 시간 경계가 흐려지는 문제도 사라진다.

### 인원 → 활동 종류

인원 기준은 절대값이 아니라 전체 대비 비율로 잡아, 5명이든 40명이든 같은 세계관으로 작동하게 한다.

| 비는 인원 | 활동 |
| --- | --- |
| 1명 | 나무 아래 낮잠, 벤치에 혼자 앉기 |
| 소수 (2\~3명 수준) | 작은 밭 농사, 모닥불 |
| 중간 | 연못 낚시, 캠핑 텐트 |
| 다수 | 큰 호수에 배, 부두와 마을 |
| 전원 | 축제, 불꽃놀이 |

### 연속 시간 → 규모

인원은 활동의 종류, 연속된 빈 시간은 그 활동의 크기로 매핑한다. 3명이 오후 내내 비면 넓은 밭, 10명이 30분만 비면 북적이는 작은 선착장이 된다.

### 바쁜 쪽과 시간대 연출

- 산은 **광산**: 수업 중인 사람은 산 속에서 곡괭이질한다.
- 세로축이 시간이므로 아침 행은 밝게, 저녁 행으로 갈수록 노을 조명과 횃불을 켠다.

### 캐릭터

- 각자 캐릭터 색이나 모자를 고른다. 친구 지도에서 내 캐릭터를 찾는 재미가 공유 동기가 된다.
- "나를 지도에서 빼기" 토글로 내 수업이 어느 산을 만드는지 보여준다.

## 여러 명이 모일 때 난잡함 줄이기

인원이 늘면 캐릭터가 아니라 마을이 커진다. 화면 정보량은 줌과 포커스로 단계적으로 늘린다.

- **마을 규모로 표현**: 텐트 하나 → 오두막 몇 채 → 부두 딸린 마을. 영역당 보이는 캐릭터는 최대 3\~5명, 나머지는 마을 입구 깃발에 숫자로 표시한다.
- **줌 3단계**: 멀리서는 지형과 소품만, 가까이 가면 캐릭터, 영역을 누르면 이름. 감상 모드와 결정 모드가 자연스럽게 나뉜다.
- **안개 포커스**: 한 영역을 선택하면 나머지는 채도를 낮추고 안개를 깐다.
- **캐릭터 중복 처리**: 한 사람이 여러 시간에 복제되지 않도록 기본 화면은 익명 소품과 실루엣만 보여주고, 영역 클릭 시 얼굴이 떠오른다. 개인정보 부담도 같이 줄어든다.

## 아쉽게 비는 사람 표현

"아쉽다"는 세 종류로 나누고, 각각 텍스트 없이 읽히는 연출을 준다.

| 유형 | 상황 | 표현 |
| --- | --- | --- |
| 인원 | 한두 명만 빠지는 시간 | 현재 수위 한 단계 아래 영역을 얕은 물·늪지대로. 빠지는 사람은 호수 옆 광산에서 곡괭이질 |
| 시간 경계 | 수업이 10\~15분 겹침 | 늦는 사람은 호수로 걸어오는 중, 일찍 가는 사람은 배를 정리하며 짐 싸는 중 |
| 본인 선호 | 비긴 하지만 애매한 시간 (알바, 통학, 식사) | 반투명 캐릭터 또는 하품하며 앉아 있는 모습 |

본인 선호 유형을 위해 각자 시간을 **수업 / 애매 / 자유** 세 단계로 직접 덧칠할 수 있게 한다. 포털 시간표엔 수업만 있기 때문이다.

## 편의성 기능

지도는 감상용, 결정은 리스트와 필터로 한다. 아트워크가 기능을 방해하지 않게 하는 게 목적이다.

- **추천 리스트**: 지도 옆에 상위 3개 시간대를 "8명 가능 · 1명 지각 · 빠지는 사람: OO" 형태로 표시한다.
- **모임 길이 필터**: "1시간 필요"를 설정하면 그보다 짧은 빈 시간은 물이 말라 맨땅이 된다.
- **필수 인원 지정**: 조장·발표자 등을 핀으로 고정하면 그 사람이 바쁜 시간은 바위로 막힌다.
- **투표와 확정**: 링크 공유 → 각자 원하는 호수에 깃발 → 최다 득표 확정 → 캘린더 파일(.ics) 내보내기. 확정된 곳에는 건물이 세워진다.
- **공유용 내보내기**: 아이소메트릭 각도 그대로 포스터 이미지(인스타 스토리 9:16)나 짧은 클립으로 저장한다.

## 시연 프로토타입

더미 16명(월\~금, 9\~21시) 데이터로 수위 슬라이더가 동작하는 시연 화면을 만들었다. 발표에서 콘셉트를 보여주는 용도다.

- 월\~수 오전은 설산과 광산, 점심시간은 대륙을 가로지르는 물길, 목·금 오후는 배가 떠 있는 큰 호수로 나온다.
- 수위를 올리면 호수가 줄고, 한 명이 모자란 칸은 늪지대로 바뀐다.
- 소수만 비는 영역은 밭, 중간은 연못과 텐트, 다수는 호수와 배, 거의 전원은 깃발 단 부두로 표시된다.
- 지도 아래에 상위 3개 후보 ("목요일 15–17시의 큰 호수 · 최대 n명 · 빠지는 사람 n명")가 리스트로 나온다.
- 소품과 캐릭터는 단순화한 초안이다. 발표용 정적 포스터 버전은 별도로 다듬는다.

## 구현 메모와 주의사항

### 구현

- **렌더링**: three.js `InstancedMesh`로 블록을 그린다. 수천 개도 가볍게 돌아간다.
- **해상도**: 30분 단위 격자는 약 6열 × 20\~28행이다. 시간 한 칸을 블록 4×4 정도로 쪼개야 밭·배 같은 소품을 올릴 공간이 생긴다.
- **카메라**: 정사영 아이소메트릭으로 고정해 디오라마 느낌을 낸다. 같은 각도로 포스터를 내보낸다.
- **수위 연출**: 물 블록이 차오르고 빠지는 애니메이션으로 슬라이더를 표현한다.

### 주의사항

- **저작권**: 복셀 스타일 자체는 자유지만, 마인크래프트 실제 텍스처, 스티브 등 캐릭터, 이름·로고는 쓰지 않는다. 블록 텍스처와 캐릭터는 오리지널로 제작한다.
- **포털 연동 보안**: 학번·비밀번호를 서버로 받는 구조는 보안·약관 문제가 생길 수 있다. 시간표 화면 캡처 OCR이나 붙여넣기 파싱이 더 안전하다.
