# [TEMP] 히트맵 수학 모델 비교 (다른 작업자가 진행 중 — 참고용 메모)

> 상태: 임시 정리. 시간표 → "의미있는 히트맵" 스칼라 필드 생성 모델 비교.
> 담당은 다른 사람이 진행하므로 여기까지만 기록해 둠.

## 문제 정의

TimeAble의 "히트맵"은 사실 **5일 × 24칸 격자 위의 스칼라 필드**다.
이 필드가 복셀 지형 높이와 수위(호수)를 결정한다.
현재 그 필드는 `free_counts`(칸별 자유 인원) — 가장 날것의 모델.

핵심 질문: **"어떤 숫자를 칸의 밝기/높이로 쓸 것인가"**

## 모델 비교 (기본 → 최신)

| # | 모델 | 수식 핵심 | 잡는 것 | 놓치는 것 | 비용 |
|---|------|-----------|---------|-----------|------|
| 0 | Raw count (현재) | `f(d,s)=Σ free` | 단순·완전 투명 | 고립 1칸과 긴 블록 동일 취급, 시간 선호 무시 | 0 |
| 1 | 정규화 + 분위수 매핑 | `g = CDF(f)` → perceptual colormap(viridis) | 대비 확보(분포 쏠림 보정) | 값 자체는 raw와 동형 | O(n log n) |
| 2 | 연속성 인지 (windowed-min / 형태학) | 길이 L 창에서 `min` 또는 자유집합 **교집합 크기** | "회의는 연속 블록이 필요" — 1칸 노이즈 제거 | 선호 가중 없음 | O(n·L) |
| 3 | 가중 점수 모델 | `Σ wᵢ·freeᵢ + 시간대 가중 t(s)` | 사람 우선순위·점심/야간 페널티 | 가중치 튜닝 필요 | 0 |
| 4 | 확률적 기대참석 (Bayesian) | 칸별 `p∈{1, 0.5, 0}` → `E=Σp`, 분산=위험 | 3단계(수업/애매/자유) 자연 수용, 신뢰도 맵 | 모델 가정 필요 | 0 |
| 5 | Gaussian Process 평활 | (day,time) 위 잠재 표면 + 불확실성 | 매끈한 지형, 상관구조, 보간 | 5×24엔 과함 | O(n³) |
| 6 | 정보이론 / 강건성 | 엔트로피 or `k명 이탈 시 최소 참석` | "이 슬롯이 얼마나 안정적인가" | 해석 난도 | O(n·k) |
| 7 | 최적화 목적함수 (ILP/max-coverage) | 최적 회의시간 선택 → Boltzmann `softmax(βE)` 로 히트맵화 | 추천의 "정답"을 직접 시각화 | 히트맵이 아니라 해(解) 지향 | 높음 |

## TimeAble 추천 (단계별)

핵심 통찰: **칸 하나의 자유 인원은 회의에 쓸 수 없는 숫자다.**
회의는 길이 L의 **연속 블록**이고, 의미 있는 숫자는 `handler`가 계산하는
`attendance`(블록 내내 자유인 사람들의 **교집합 크기**). raw count(`min_free`)와
`attendance`가 다르다는 건 데이터 스킬 문서도 명시.

- **1단계 (모델 #2):** 지형 높이·호수를 raw count가 아니라 **windowed-intersection
  attendance**로. 각 칸 (d,s)에서 "길이 L(=회의 시간, 슬라이더) 창의 교집합 자유 인원".
  `handler` 블록 로직을 칸 단위로 펼치면 됨. → `attendance_field(data, min_duration)` 제안.
- **2단계 (모델 #1):** 그 스칼라를 **분위수 정규화** → perceptual colormap. 인원 분포가
  10~15명에 쏠려도 대비가 산다.
- **3단계 (모델 #4, 3상태 확장 시):** 수업/애매/자유 → `p∈{0, 0.5, 1}` 기대참석.
  "애매"가 반투명 늪지로 렌더, 분산을 신뢰도 레이어로. 기획안 반투명 캐릭터와 맞물림.
- **선택 (모델 #7):** `top_candidates`를 Boltzmann `softmax(β·attendance)`로 → 추천 강도를
  연속값으로 겹치기. GP(#5)·엔트로피(#6)는 5×24 격자엔 과투자, 보류 권장.

## 한 줄 결론

raw count는 버리고 **"회의 길이만큼의 연속 교집합 참석자 수"를 스칼라로** 쓰는 게 가장 알맞다.
최신 기법(GP·ILP)은 격자가 작아 효용 대비 비용이 안 맞음.
확률적 기대참석(#4)이 3단계 확장과 맞물리는 다음 투자처.
