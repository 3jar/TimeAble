# TimeAble 초기 모델 설명

TimeAble은 **수업 때문에 바쁜 정도와 과제 때문에 부담스러운 정도를 합쳐, 여러 사람의 시간대를 3D 지형으로 보여주는 모델**이다.

날짜와 시간을 바닥의 두 축으로 두고, 그룹의 평균 부담을 높이로 표현한다. 낮은 곳은 평균 부담이 적고, 높은 곳은 평균 부담이 크다.

계산은 **과제별 마감·가중치 → 개인 과제 부담 → 수업과 결합 → 그룹 지형 높이** 순서로 진행된다.

## 1. 과제 하나의 부담은 어떻게 정하는가?

과제 부담에는 두 가지를 반영한다.

- **마감까지 남은 시간:** 마감이 가까울수록 부담이 커진다.
- **과제 가중치:** 작업량이 큰 과제일수록 더 이른 시점부터 부담이 커진다.

가중치는 사용자가 1~10으로 조정하며 기본값은 1이다. 예상 작업시간을 가중치로 사용하지만, 실제로 어느 시간에 몇 시간씩 작업할지는 계산하지 않는다.

남은 시간을 $d$시간, 가중치를 $h$라고 하면 부담 함수는 다음과 같다.

```math
f(d,h)=\min\left(1,\max\left(0,1.25-\frac{d}{6(h+1)}\right)\right)
```

안쪽의 최댓값 연산은 0보다 작은 결과를 0으로, 바깥쪽의 최솟값 연산은 1보다 큰 결과를 1로 제한한다. 따라서 부담은 항상 0~1이다.

| 마감까지 남은 시간 | 가중치 1의 부담 | 마감까지 남은 시간 | 가중치 3의 부담 |
|---|---:|---|---:|
| 15시간 이상 | 0 | 30시간 이상 | 0 |
| 12시간 | 0.25 | 24시간 | 0.25 |
| 9시간 | 0.5 | 18시간 | 0.5 |
| 6시간 | 0.75 | 12시간 | 0.75 |
| 3시간 이하, 마감 전 | 1 | 6시간 이하, 마감 전 | 1 |

표 사이에서는 직선적으로 변한다. 예를 들어 가중치 1인 과제는 마감 7.5시간 전에 부담이 0.625다.

**가중치는 최대 높이를 올리는 대신, 부담이 나타나는 시간 범위를 넓힌다.** 최대 부담은 어떤 가중치에서도 1이다.

식에서 두 경계를 구하면 다음과 같다.

```math
\text{부담이 0인 범위:}\quad d\ge7.5(h+1)
```

```math
\text{부담이 1인 범위:}\quad 0<d\le1.5(h+1)
```

따라서 가중치 1은 3시간 전부터, 가중치 3은 6시간 전부터, 가중치 10은 16.5시간 전부터 최대 부담에 도달한다.

### 제출하거나 마감이 지나면?

**미제출이고 마감 전인 과제만 계산한다.**

- 제출이 확인되면 마감 전이라도 즉시 제외한다.
- 미제출이어도 마감 시각에 도달하면 제외한다.
- 마감 직전의 부담이 1이어도, 마감부터 해당 과제의 영향은 사라진다.

따라서 위 함수는 $d>0$인 계산 대상 과제에만 적용한다.

## 2. 한 사람에게 과제가 여러 개라면?

과제마다 마감이 다르므로 모든 가중치를 한 번에 더해서 하나의 마감에 적용할 수는 없다.

대신 **각 마감까지 끝내야 하는 과제들의 가중치를 누적하고, 마감별 부담 중 가장 큰 값을 사용한다.**

예를 들어 현재 다음 두 과제가 있다고 하자.

| 과제 | 마감까지 남은 시간 | 가중치 |
|---|---:|---:|
| A | 9시간 | 1 |
| B | 15시간 | 3 |

A의 마감까지는 A만 고려하므로 누적 가중치는 1이다.

```math
f(9,1)=1.25-\frac{9}{6(1+1)}=0.5
```

B의 마감까지는 A와 B를 모두 끝내야 하므로 누적 가중치는 $1+3=4$다.

```math
f(15,4)=1.25-\frac{15}{6(4+1)}=0.75
```

따라서 이 사람의 과제 부담은 다음과 같다.

```math
P=\max(0.5,0.75)=0.75
```

여기서 최댓값은 **개별 과제 점수의 최댓값이 아니라, 누적 가중치로 계산한 마감별 부담의 최댓값**이다. 가장 부담이 큰 마감 구간이 현재의 과제 부담을 결정한다.

### 일반식

사람 $i$의 시각 $t$에서 미제출이고 마감 전인 과제 집합을 $\mathcal{A}_i(t)$라고 하자. 과제 $k$의 마감은 $D_{ik}$, 가중치는 $h_{ik}$다.

특정 마감 $D$까지의 누적 가중치는:

```math
H_i(D;t)=
\sum_{k\in\mathcal{A}_i(t),\;D_{ik}\le D}h_{ik}
```

이 과제들의 서로 다른 마감 시각을 모은 집합을 $\mathcal{D}_i(t)$라고 하자. 마감 $D$까지 남은 시간을 시간 단위로 나타낸 값은 $d(D;t)$다. 즉, 마감이 9시간 뒤라면 $d(D;t)=9$다.

개인 과제 부담은 계산 대상 과제가 있을 때 다음과 같다.

```math
P_i(t)=
\max_{D\in\mathcal{D}_i(t)}f\left(d(D;t),H_i(D;t)\right)
```

계산 대상 과제가 없으면 $P_i(t)=0$으로 둔다.

동일한 마감의 과제는 함께 합산한다. 과제별 가중치는 최대 10이지만 **누적 가중치는 10을 넘을 수 있다.** 제출하거나 마감에 도달한 과제는 누적 합에서도 빠진다.

예시에서 A를 제출하면 B만 남으므로, 같은 시각의 부담은 $f(15,3)=0.625$로 내려간다.

## 3. 과제 부담과 수업 여부를 어떻게 합치는가?

수업 여부는 각 시각에서 0 또는 1이다.

- 수업 중이면 $C_i(t)=1$.
- 수업이 없으면 $C_i(t)=0$.

개인의 최종 부담 $B_i(t)$는 다음과 같다.

```math
B_i(t)=C_i(t)+(1-C_i(t))P_i(t)
```

말로 풀면 **수업 중에는 1, 수업이 없으면 과제 부담을 사용한다.**

| 수업 여부 | 과제 부담 | 개인 최종 부담 |
|---|---:|---:|
| 있음 | 0 | 1 |
| 있음 | 0.75 | 1 |
| 없음 | 0.75 | 0.75 |
| 없음 | 0 | 0 |

수업과 과제가 겹쳐도 한 사람의 부담은 1을 넘지 않는다. 다만 수업 때문에 1인 경우와 과제 때문에 1인 경우는 상세 정보에서 구분한다.

## 4. 여러 사람의 부담을 어떻게 높이로 만드는가?

어떤 순간에 세 사람의 최종 부담이 다음과 같다고 하자.

| 사람 | 상황 | 최종 부담 |
|---|---|---:|
| A | 수업 중 | 1 |
| B | 수업 없음, 과제 부담 0.75 | 0.75 |
| C | 수업 없음, 과제 부담 0 | 0 |

이 순간의 그룹 평균 부담은:

```math
\frac{1+0.75+0}{3}\approx0.583
```

**사람 수로 나누므로 인원수가 달라도 높이는 항상 0~1이다.** 같은 점수에 같은 지형 색상과 높이를 대응시킬 수 있다.

다만 높이는 그룹의 **평균 부담**이다. 0.583을 “58.3%가 참석 불가능하다”는 뜻으로 해석하지 않는다.

또한 네 사람의 점수가 $(1,1,0,0)$일 때와 $(0.5,0.5,0.5,0.5)$일 때는 모두 평균 0.5다. 이 차이는 개인별 정보를 보존하고, 마우스를 올렸을 때 보여준다.

## 5. 50분·75분 수업을 1시간 블록에 어떻게 반영하는가?

화면은 09:00~24:00을 1시간 블록으로 나누지만, 계산은 각 블록 안에서 1분 간격으로 한다.

각 분의 가운데 시각에서 개인 부담을 구한 뒤, **60분과 전체 사람에 걸쳐 평균**을 낸다.

블록 시작이 $s$, 인원수가 $N\ge1$일 때:

```math
t_m=s+(m+0.5)\text{분},\qquad m=0,\ldots,59
```

```math
\boxed{
Z_{\text{블록}}
=\frac{1}{60N}
\sum_{m=0}^{59}\sum_{i=1}^{N}
\left[C_i(t_m)+(1-C_i(t_m))P_i(t_m)\right]
}
```

이 $Z_{\text{블록}}$이 실제 3D 지형의 높이다.

예를 들어 09:00~10:15 수업이 있고 과제 부담이 없는 사람은 다음과 같이 반영된다.

| 블록 | 수업에 해당하는 시간 | 개인 블록 평균 |
|---|---:|---:|
| 09:00~10:00 | 60분 | 1 |
| 10:00~11:00 | 15분 | 0.25 |

수업 여부 자체는 계속 0 또는 1이다. 0.25는 **한 시간 중 수업이 있었던 구간을 평균낸 결과**다. 수업 구간은 시작 시각을 포함하고 종료 시각은 제외한다. 수업 사이의 쉬는 시간도 그대로 남긴다.

과제 부담도 각 분마다 평가한다. 블록 중간에 마감이 있으면 마감 이전 평가 시각에만 해당 과제를 포함한다. 1분 표본을 평균내는 방식이므로 초 단위 경계의 영향은 근사적으로 반영된다.

평균이 낮더라도 모두가 동시에 비어 있다는 뜻은 아니다. 한 사람은 앞 30분, 다른 사람은 뒤 30분 수업일 수 있으므로, 상세 정보에는 사람별 실제 수업 구간을 함께 보여준다.

## 6. 이 모델이 표현하는 것

| 반영 요소 | 지형에 나타나는 효과 |
|---|---|
| 같은 구성원에서 수업이 있는 사람 증가 | 해당 구간의 높이가 증가하거나 상한에 머묾 |
| 과제 마감이 가까워짐 | 마감 전 부담이 증가하거나 상한에 머묾 |
| 과제 가중치 증가 | 부담이 더 이른 시점부터 나타남 |
| 미완료 과제가 겹침 | 마감별 누적 가중치가 커져 부담이 증가하거나 상한에 머묾 |
| 과제 제출 또는 마감 도달 | 해당 과제를 제외하고 높이를 다시 계산 |
| 그룹 인원수 변화 | 평균으로 계산하여 높이 범위 0~1 유지 |

부담 함수의 계수는 **TimeAble의 초기 설계값**이다. 가중치 1은 마감 3시간 전, 가중치 3은 6시간 전부터 최대 부담이 되도록 정했다. 실제 스트레스나 참석 가능성을 검증한 수치는 아니다.

미래 지형은 현재 확인된 미제출 과제를 기준으로 계산한다. 앞으로 얼마나 작업할지 또는 언제 제출할지는 예측하지 않는다. 가중치나 제출 상태가 바뀌면 결과도 달라진다.

최종적으로 지형은 **이 시간대의 그룹 평균 부담**을 보여주고, 개인별 상세 정보는 **누가 어떤 이유로 바쁜지**를 설명한다.
